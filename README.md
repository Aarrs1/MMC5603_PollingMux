# ESP32-S3 双 I2C 多路复用器 16 路 MMC5603 传感器测量系统

## 项目概述

基于 **ESP32-S3** 的高性能磁场测量系统，通过两个 **I2C 多路复用器（地址 0x77）** 控制 **16 路 MMC5603 三轴磁力计传感器**，实现非阻塞并行测量与高速数据采集。

## 硬件配置

### I2C 总线配置
- **总线 0**：SDA=GPIO12, SCL=GPIO11, 频率 400kHz
- **总线 1**：SDA=GPIO3, SCL=GPIO8, 频率 400kHz

### 多路复用器
- **地址**：0x77（两个复用器使用相同地址）
- **通道**：每个复用器 8 路，共 16 路传感器

### 传感器
- **型号**：MMC5603 三轴磁力计
- **地址**：0x30
- **分辨率**：20 位
- **测量范围**：±30 高斯（±3000 μT）

## 核心功能

### 1. I2C 多路复用器控制
- `selectChannel()` 函数快速选择指定通道
- 控制字节启用单通道（`1 << channel`）
- 5μs 微秒级切换保证稳定性

### 2. MMC5603 初始化配置
- **带宽设置**：最大带宽（寄存器 0x1C = 0x03），测量时间约 1.2ms
- **自动去磁**：启用 SET/RESET 去磁（寄存器 0x1B = 0x20）
- 支持单次测量启动和多字节寄存器读取

### 3. 非阻塞状态机设计
三阶段循环实现高效数据采集：

1. **START_MEASURE**：一次性启动全部 16 个传感器测量
2. **WAIT**：基于时间戳的非阻塞等待（3.8ms 确保测量完成）
3. **READ**：读取全部传感器数据，CSV 格式串口输出

### 4. 数据处理
- 每个传感器三轴数据为 20 位值
- 位拼接：`buf[0]<<12 | buf[1]<<4 | buf[6]&0x0F`
- 输出格式：`F,x1,y1,z1,x2,y2,z2,...,x16,y16,z16`

### 5. 高速通信优化
- **I2C 频率**：400kHz
- **串口波特率**：921600 bps
- **输出方式**：`Serial.print` 高效输出，避免 printf 开销
